# 七日練功試算

一週掛機與團練配置試算器。調整每天的商店購買、結晶體／羽毛兌換、背包庫存石頭與團練時數，就能看到每天的遊玩時數、經驗與等級。按「一鍵最佳化」會算出經驗最高的兌換與庫存用法。

## 功能

- 每日配置表：商店購買、結晶體兌換、羽毛兌換、庫存石頭使用、可玩上限、團練時數
- 即時計算：每天的掛機時數、團練、總遊玩時數、經驗、日終等級，以及剩餘資源
- 一鍵最佳化：用整數線性規劃（[javascript-lp-solver](https://github.com/JWally/jsLPSolver)）求出最佳兌換組合
- 方案比較：只買商店、每天換 4 顆 ATS，以及每天玩 16／17／18 小時的最佳方案
- 等級進度圖，可以把任一方案鎖定成比較基準
- 所有遊戲數值都可以在設定裡改；設定會存在瀏覽器的 localStorage

## 計算模型

- 掛機時數 = min(地圖可用時數, ATS 可用時數, 當天可玩時數)，先排暗影神殿，再排被遺棄者之地
- 沒掛機的可玩時間都拿去團練，經驗依每 3 小時 7% 按比例計算
- 經驗以起始等級的一整級 = 100% 為單位。預設實際經驗固定，每升一級需求 +5%
- 羽毛每天新增，當天沒用完會累積；結晶體在第一天就全部可用

## 檔案

- `index.html`：頁面與樣式
- `model.js`：計算與最佳化模型（純函式）
- `app.js`：介面邏輯

純靜態網站，不需要建置，直接用 GitHub Pages 從 `main` 分支根目錄部署即可。
