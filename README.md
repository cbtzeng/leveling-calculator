# 七日練功試算

一週掛機與團練的時數規劃工具。每天填可玩時數、團練、被遺棄者之地、暗影神殿四個數字，ATS 時數自動加總。頁面會算出每天要用多少石頭、要用羽毛和結晶體換多少，資源不夠時標出從哪一天開始缺。

網站：https://cbtzeng.github.io/leveling-calculator/

## 功能

- 每日時數表：可玩、團練、被遺棄者之地、暗影神殿；自動顯示 ATS 時數、時間是否超過、當天經驗與日終等級
- 石頭來源表：每天要用的石頭、建議羽毛兌換、建議結晶體兌換、羽毛／結晶體／背包餘額，不足時標紅
- 「使用羽毛兌換」開關
- 「幫我排經驗最多的時數」：依每天可玩時數，排出資源夠用、經驗最多的時數
- 遊戲數值與資源都可在設定修改，設定存在瀏覽器 localStorage

## 計算規則

- ATS 時數 = 被遺棄者之地 + 暗影神殿；每天免費被遺棄者之地 3 h、暗影神殿 1 h、ATS 3 h，超過部分每小時 1 顆石頭
- 商店每天各買 3 顆，買的和換的石頭都進背包，可以留到之後用
- 兌換用整數線性規劃（[javascript-lp-solver](https://github.com/JWally/jsLPSolver)）找整週最省的配法：優先用羽毛，再用結晶體，並遵守每日兌換上限
- 經驗以起始等級一整級 = 100% 計算，每升一級需求 +5%
